# Taller00

Escriba un programa que le pida al usuario que ingrese su estatura en metros (m) y su peso en
kilogramos (kg). El programa debe calcular el índice de masa corporal (IMC).

## Refinamiento 1 
1. Pregunto y obtengo la estatura.
2. Pregunto y obtengo el peso.
3. Calculo el IMC a partir del producto y cociente de los datos. 
4. Clasifico el IMC y entrego el resultado al usuario. 

## Refinamiento 2
1. Defino variable 1 `est`
2. Defino variable 2 `peso`
3. Defino variable 3 `IMC`
3. Solicito estatura a usuario 
4. Obtengo valor y asigno variable `est`
5. Solicito peso a usuario 
6. Obtengo valor y asigno variable `peso`
7. Obtengo cociente de `peso` entre la potencia de `est` y asigno variable `IMC`
8. Imprimo tabla
9. Aplico condicional para IMC 'Peso bajo'
10. Si IMC='Peso bajo', imprimo resultado.
11. Aplico concicional para IMC 'Peso normal'.
12. Si IMC='Peso normal', imprimo resultado.
13. Aplico condicional para IMC 'Sobrepeso'.
14. Si IMC='Sobrepeso', imprimo resultado.
15. Aplico condicional para IMC 'Obesidad'
16. Si IMC='Obesidad', imprimo resultado.
